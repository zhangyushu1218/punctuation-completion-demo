# 测试用例字符编码问题修复

## 问题描述

运行 `test_extended_punctuation.py` 时，以下测试用例失败：

```
输入: '他说："你好"'
输出: '他说"你好"'
期望: '他说："你好"'
测试失败: 清洗结果不匹配！
```

冒号字符被错误地移除了。

## 根本原因

**字符编码不一致**：测试用例文件中直接使用的中文字符（冒号、引号）可能与 `utils.py` 正则表达式中定义的字符不是完全相同的Unicode码点。

可能的情况：
1. 编辑器在保存文件时使用了不同的编码
2. 复制粘贴时引入了相似但不同的字符
3. 输入法在不同时间输入了不同版本的标点符号

## 解决方案

使用 **Unicode转义序列** 替代直接的中文字符，确保绝对的字符一致性：

### 修改前
```python
("他说："你好"", "他说："你好""),
```

### 修改后
```python
# 使用Unicode转义确保字符一致性：冒号U+FF1A，左引号U+201C，右引号U+201D
("他说\uff1a\u201c你好\u201d", "他说\uff1a\u201c你好\u201d"),
```

## Unicode字符对照表

| 标点符号 | Unicode转义 | Unicode码点 | 字符名称 |
|---------|------------|------------|---------|
| ， | `\uff0c` | U+FF0C | 中文全角逗号 |
| 。 | `\u3002` | U+3002 | 中文句号 |
| 、 | `\u3001` | U+3001 | 中文顿号 |
| ！ | `\uff01` | U+FF01 | 中文全角感叹号 |
| ？ | `\uff1f` | U+FF1F | 中文全角问号 |
| ： | `\uff1a` | U+FF1A | 中文全角冒号 |
| ； | `\uff1b` | U+FF1B | 中文全角分号 |
| " | `\u201c` | U+201C | 左双引号 |
| " | `\u201d` | U+201D | 右双引号 |

## 为什么使用Unicode转义？

### 优点
1. **绝对一致性**: 无论文件编码如何，`\uff1a` 永远代表 U+FF1A
2. **可读性**: 明确显示使用的是哪个Unicode字符
3. **可维护性**: 便于检查和验证
4. **跨平台**: 在不同操作系统和编辑器之间保持一致

### 缺点
1. 不如直接字符直观
2. 需要查阅Unicode码点表

## 最佳实践

### ✅ 推荐做法
```python
# 在测试用例中使用Unicode转义
test_cases = [
    ("他说\uff1a\u201c你好\u201d", "他说\uff1a\u201c你好\u201d"),
]
```

### ❌ 避免做法
```python
# 直接使用中文字符（可能因编辑器/编码导致不一致）
test_cases = [
    ("他说："你好"", "他说："你好""),
]
```

## 验证方法

可以通过以下脚本验证字符是否正确：

```python
test = "他说\uff1a\u201c你好\u201d"
for i, char in enumerate(test):
    print(f"[{i}] '{char}' - U+{ord(char):04X}")
```

预期输出：
```
[0] '他' - U+4ED6
[1] '说' - U+8BF4
[2] '：' - U+FF1A  ← 中文全角冒号
[3] '"' - U+201C  ← 左双引号
[4] '你' - U+4F60
[5] '好' - U+597D
[6] '"' - U+201D  ← 右双引号
```
